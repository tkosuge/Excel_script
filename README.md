# Excel_script
エクセル365のスクリプトです

# 準備
メニューの「自動化」→「新しいスクリプト」→「コードエディタで作成」を選ぶ
このrepositoryにある各スクリプトをコピーして、コードエディタにペーストし、コードエディタの名前の変更機能で、好きな名前に変える

# 機能
### 塩基配列を1行形式にする.osts
Fasta形式の配列をEntryName[tab]Sequenceの形式にし、1エントリーを1行で表す形式に変換します。
### Entry name重複チェック.osts
Annotationファイル内のEntry nameの重複使用と1 entryにsourceが複数使われていることを検出します。
### sourceをパースして表形式にする.osts
sourceフィーチャーフィールドと、第一biologicalフィーチャーを取り出して、表形式に変換します。

# 使い方
1. エクセル365を起動
2. **1から5列目までのセル書式を文字列にしておいてから**、Annotationファイルの中身をシートに貼り付けます。貼り付けてからセルの書式変更をしないこと、そのシートを表示しておきます。
3. メニューの「自動化」→「スクリプトの表示」→「最近使用したスクリプト」
  または、メニューの「自動化」→「Officeスクリプトギャラリー」内の最近使用したスクリプトを選択して、「実行」

「塩基配列を1行形式にする」 を使う場合
- 上記2.で、Sequeceファイルの中身をシートに貼り付け、そのシートを表示しておく
