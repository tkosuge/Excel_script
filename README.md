# Excel_script
エクセル365のスクリプトです

# 準備
メニューの「自動化」→「新しいスクリプト」→「コードエディタで作成」を選ぶ
Entry name重複チェック.ostsをコピーして、コードエディタにペースト
コードエディタの、名前の変更で、好きな名前に変える

# 機能
ファイル名の通りです

# 使い方
1. エクセル365を起動
1. Annotationファイルの中身をシートに貼り付ける
1. メニューの「自動化」→「スクリプトの表示」→「最近使用したスクリプト」
  または、メニューの「自動化」→「Officeスクリプトギャラリー」内の最近使用したスクリプトを選択して、「実行」
