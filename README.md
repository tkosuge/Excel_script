# Excel_script
エクセル365のスクリプトです

# 準備
メニューの「自動化」→「新しいスクリプト」→「コードエディタで作成」を選ぶ
このrepositoryにある各スクリプトをコピーして、コードエディタにペーストし、コードエディタの名前の変更機能で、好きな名前に変える

# 機能
ファイル名の通りです

# 使い方
1. エクセル365を起動
2. Annotationファイルの中身をシートに貼り付け、そのシートを表示しておく
3. メニューの「自動化」→「スクリプトの表示」→「最近使用したスクリプト」
  または、メニューの「自動化」→「Officeスクリプトギャラリー」内の最近使用したスクリプトを選択して、「実行」

「塩基配列を1行形式にする」 を使う場合
- 上記2.で、Sequeceファイルの中身をシートに貼り付け、そのシートを表示しておく
